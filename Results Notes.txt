- For all noisy dataset CNN models there is overfitting early on in training which triggers the early stopping.
- The CNN's dramatic advantage on raw 208-feature data (+17.5pp over RF in noisy?noisy) likely stems from:
o Spatial structure exploitation: The 1D-CNN treats the 208 measurements as a sequence with local correlations (adjacent electrode pairs). Convolutional filters can learn spatial patterns that are noise-invariant.
o Hierarchical feature learning: The 3-layer architecture extracts increasingly abstract representations, potentially isolating conductivity-change patterns from noise patterns.
o Redundancy utilisation: Raw data has many correlated measurements (208 from 16 electrodes); the CNN can learn to average across these for denoising, while RF/SVM treat each feature independently.
- PCA and LDA reduced datasets show near-zero benefit from noise training. This is because:
o Information loss: PCA/LDA projections optimised on clean data project away variance that happens to correlate with noise structure. The model cannot learn noise-invariance if the noise-relevant subspace is already removed.
o Noise amplification in reduced space: In low-dimensional projections, additive noise has proportionally larger impact (SNR is lower per-component).
o Missing redundancy: The CNN's noise robustness relies on exploiting measurement redundancy � dimensionality reduction eliminates this redundancy by design.
Implication for practice: For noise-robust EIT classification, use the full (or minimally reduced) measurement vector. Aggressive feature engineering is counterproductive for robustness.
